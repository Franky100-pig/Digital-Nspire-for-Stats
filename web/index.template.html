The syntax is the calculator's own, not Python's:

  • a list is {1,2,3} — braces, and no spaces needed
  • an optional argument you skip stays an empty field: tInterval v,sx,n,,0.95
  • every calculation parks its answer in stat. — read it back with stat.Q1X, or in the next line with stat.v * 2
  • name a list with A = {3,1,4}, then use A anywhere an argument goes
