The front panel follows the TI‑Nspire CX II layout; the keys and their names are from TI's handheld key reference. Function names, argument order and the stat. result names are copied from the TI‑Nspire Reference Guide. The menu key walks the handheld's own menus — numbering included — so 4 1 1 lands on One-Variable Statistics the way it does on the device.

Everything runs in your browser and nothing is uploaded. The Python interpreter is served from this same site, so the page needs no third-party CDN — the first visit downloads it once (about 13 MB) and the browser keeps it. The doc key, or typing help, shows the syntax card.
